# Take Ownership Context Menu for Windows

A simple, lightweight Windows tool that adds a **"Take Ownership"** option to your right-click context menu. It allows you to take ownership and grant Full Control permissions over locked, restricted, or stubborn files and folders in Windows 10 & 11.

---

## 🚀 How to Install

1. **Download** or clone this repository anywhere on your computer (e.g., `C:\tools\take_ownership` or your preferred folder).
2. **Double-click `install.cmd`**.
   - It will automatically detect your folder location and register the context menu in Windows.
3. Done! The **"Take Ownership"** option is now available in your right-click menu.

---

## 📖 How to Use

1. **Right-click** any file or folder you want to unlock.
   > **Windows 11 tip:** If you use the modern context menu, click **Show more options** to see "Take Ownership".
2. Select **Take Ownership**.
3. Click **Yes** on the Windows UAC (Administrator) prompt.
4. A console window will appear showing each file being processed.
5. When finished, press **Enter** to close the window.

You can now freely rename, edit, move, or delete the file/folder without permission errors!

---

## 🗑️ How to Uninstall

1. Double-click **`uninstall.cmd`**.
2. The context menu shortcut will be completely removed from your system.
